## Description
A mobile application designed for roommates to manage shared
responsibilities and expenses. The app allows users to create and
track to-dos such as cleaning, paying rent, utilities, and
purchasing shared items. It also includes a bill-splitting
feature for shared costs (e.g., groceries, dining out,
activities). Once one roommate completes a task, they can confirm
it in the app and all others will be notified, ensuring
transparency and reducing miscommunication in shared living.

## MVP Statement
An app that lets roommates add and assign chores, track
completion, and receive notifications to ensure shared
responsibilities are transparent and fairly managed.
## MVP Features and User
- Our app is meant for people living with one or more roommates,
particularly those who struggle to manage responsibilities
- Users can create and track chores
- In the app, you can create a chore group, where the creator is
the administrator
- In the group you have a task view
- Within the group, task will be auto-split
- Bill splitting: there is a dashboard/list of all the things you
buy, assigned to the buyer
- Checkboxes for all the users user the item
- For each item that a person checks, it splits the price based
on the # of people who check the split
- Push notification system
